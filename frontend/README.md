# Frontend

Aplicação Angular do catálogo de jogos e eventos.

## Desenvolvimento

Com Node.js e npm compatíveis com `package.json`, instale dependências e inicie a aplicação:

```sh
npm ci
npm start
```

Use o equivalente desses comandos no terminal do seu sistema operacional. Ferramentas do projeto são instaladas localmente; não é necessário instalar Angular CLI globalmente.
